# ⚡ Claude Code — установка одной командой

Ставит **Node.js, Git, VS Code, Claude Code** (расширение + терминал) и основные **плагины**.

## 🍎 Mac
Терминал (`Cmd+Пробел` → «Терминал»), вставь:
```bash
curl -fsSL https://raw.githubusercontent.com/skiddgoddamn/claude-install/main/install.sh | bash
```
Спросит пароль от Mac — вводи, символы не видны, это нормально.

## 🪟 Windows
Пуск → **PowerShell**, вставь:
```powershell
irm https://raw.githubusercontent.com/skiddgoddamn/claude-install/main/install.ps1 | iex
```
На «Разрешить изменения?» жми **Да**.

## Потом
Открой **VS Code** → значок Claude справа сверху → **Sign in**.
